# Hermes Google Workspace branding

Public static homepage, privacy policy, and terms for an owner-operated personal OAuth integration. No tokens, private calendar data, analytics, or application backend belong in this repository.

Deployment: GitHub Pages from the main branch root.
Recovery: revert the public content commit or unpublish the Pages site through repository settings. OAuth publishing status can be returned to Testing through Google Auth Platform Audience; doing so reintroduces testing restrictions.
