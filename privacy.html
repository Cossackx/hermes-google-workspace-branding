Privacy policy

This policy covers the owner-operated Hermes Google Workspace OAuth integration. It does not replace Google's, GitHub's, or an AI provider's own privacy policy.

Google data accessed and purpose

With the owner's consent, the Calendar integration can access calendar identifiers and names, events and their titles, times, descriptions, locations, attendee information, and related metadata. Data is used to answer the owner's requests, organize schedules, and perform owner-authorized calendar actions. Information about other people within events is treated as part of the owner's private calendar data.

Processing and sharing

The connection runs in the owner's Hermes environment and communicates with Google's APIs. Calendar information returned to the assistant may become part of prompts sent to the configured cloud AI provider, as well as chat replies delivered through the owner's configured messaging services. Those providers process data under their own terms and settings; this integration cannot promise local-only processing or zero provider retention.

Calendar data is not published on this site. The operator does not sell Google user data, use it for advertising, or use it to train a general-purpose AI model. The integration does not intentionally supply Google user data for general-purpose model training. Processing by third-party providers is subject to the owner's selected provider settings and applicable policies.

Storage and protection

OAuth credentials for the current Google Workspace CLI connection are stored encrypted in the owner's local environment. Calendar excerpts may remain in local session history, task artifacts, and messages produced in response to owner requests. Any owner-directed retention in other storage is governed by that destination's privacy and access settings. There is no single automatic deletion period across these systems. The public branding repository contains only site content, not credentials or calendar records.

Revocation, retention, and deletion

The owner can disconnect the app at Google Account connections to stop future authorized API access. Revocation does not delete Google calendar records, previously saved session history, or delivered messages. The owner can remove retained copies in their local environment and the relevant messaging/provider systems, subject to those systems' deletion and retention rules. For questions or deletion requests concerning copies controlled by the operator, contact razsoc.01@gmail.com. Do not include secrets or sensitive event details.

Limited use

The operator's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. If a proposed configuration cannot meet these requirements, it must not process Google user data.

This public website

These are static pages hosted by GitHub Pages. They do not contain application analytics, tracking scripts, sign-in forms, or a calendar-data collection endpoint. GitHub may collect technical request information when serving the pages; see GitHub's privacy statement.

Changes and contact

This policy will be updated when the integration's data practices change. Effective date: October 5, 2026. Contact: razsoc.01@gmail.com.
